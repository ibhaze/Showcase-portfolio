# 📌 Portfolio Website – Praise Ibhaze

A responsive personal portfolio website showcasing my work in mobile development, web development, and UI/UX design.  
The site includes a custom cursor interaction, scroll-based animations, and detailed project case studies.

---

# ✨ Features

## 🎯 Cursor-follow.js 
- Smooth trailing outer circle  
- Inner circle stays inside the main circle  
- Cursor color changes based on background contrast  
- Enlarged cursor when hovering links  



## ⏳ index.js
- Counts from **0 → 100**  
- Plays a drag-down animation  
- Redirects to `homepage.html`  
https://github.com/user-attachments/assets/362b64b8-af71-4ad1-9c22-a6246db93294

## 📌 Navigation
- Logo + section anchors  
- **ABOUT** and **PROJECTS** links

  

## 🔗 Contact Section
- LinkedIn  
- GitHub  
- Email  
- QR Code generated using **QRCode.js**  

## 🎬 Scroll Reveal Animations
- Powered by **IntersectionObserver**  
- Respects `prefers-reduced-motion`  
- Animations replay when scrolling back up  

## 📱 Project Case Study Pages
- **WISH 'N TOSS** – toy exchange mobile app  
- Screens, processes, problems, and outcomes  
- “Next Project” navigation

# Key Scripts Overview
## Loader Script

- Increments a counter from 0–100

- Triggers exit animation

- Redirects to homepage

## Cursor Script

- Smooth mouse-follow animation

- Clamped inner circle

- Dynamic color contrast detection

- Enlarges on link hover

## Scroll Reveal

- Adds is-visible when elements enter viewport

- Removes on exit so the animation can replay
